# Proyecto02: Índice de cobertura nubosa.
El proyecto se enfoca en calcular el Índice de Cobertura Nubosa (CCI) a partir de imágenes capturadas por una estación atmosférica.
El CCI se calcula como el cociente entre el número de píxeles clasificados como nube y el total de píxeles en el área de interés, proporcionando información crucial sobre las condiciones climáticas basada en las imágenes capturadas.
